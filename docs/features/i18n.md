# Especificación Técnica: Internacionalización con Paraglide-JS (v0.3 / Milestone 3)

> Documento de diseño arquitectónico y contratos de integración para el soporte bilingüe (Inglés/Español) en Pomody mediante Paraglide-JS y Svelte 5 Runes.

---

## 1. Contexto y Objetivos

El **Milestone 3** ([`docs/roadmap.md`](../roadmap.md)) establece como prioridad **P0** dotar a Pomody de soporte multiidioma completo (Inglés base y Español) sin degradar las garantías del sistema:

- **Cero dependencias pesadas en runtime**: Paraglide-JS compila a funciones puras de TypeScript tree-shakeables, evitando librerías de i18n voluminosas en memoria (<30 MB RAM target).
- **Paridad estricta Web y Desktop (Tauri v2)**: Al tratarse de una SPA empaquetada estáticamente (`@sveltejs/adapter-static`), el sistema prescinde de enrutamiento por URL (`/es/`, `/en/`) y opera íntegramente en memoria (`in-memory SPA`).
- **Reactividad instantánea sin recarga**: La conmutación de idioma en caliente actualiza los textos en el DOM de forma reactiva y determinista.

---

## 2. Principios de Arquitectura

1. **Aislamiento del Dominio Hexagonal**:
   El código en `src/lib/domain/` permanece 100% puro en TypeScript. No importa Paraglide ni dependencias de presentación. Las entidades emiten estados semánticos (`'focus'`, `'short-break'`, `'long-break'`) y códigos de error; las traducciones se resuelven exclusivamente en los componentes de UI.
2. **Reactividad Fina en Svelte 5 (Proxy `t`)**:
   Paraglide genera funciones normales de TypeScript (`m.*()`) que leen una variable interna (`_languageTag`). Para vincular estas llamadas al grafo reactivo de Svelte 5 sin obligar al remonte de vistas (`{#key}`), se introduce un proxy reactivo `t` que suscribe automáticamente cada llamada al estado reactivo del locale.
3. **Persistencia Local Desacoplada**:
   La preferencia de idioma se almacena de forma persistente en `localStorage` bajo la clave `pomody_locale`, restaurándose de forma síncrona al iniciar la aplicación (fallback a `'en'`).
4. **Traducción Semántica de Hábitos Predefinidos**:
   Las actividades predefinidas de descanso (`PRESET_BREAK_ACTIVITIES`) conservan IDs semánticos fijos en el dominio (`preset-neck-shoulder-stretch`). La UI traduce título y guía basándose en el ID si `isPreset: true`. Las actividades y tareas creadas por el usuario permanecen inalteradas con su texto original.

## 3. Arquitectura del Módulo de Estado (`locale.svelte.ts`)

Ubicación: `src/lib/state/locale.svelte.ts`.

```mermaid
flowchart LR
    SettingsDrawer["Settings Drawer / UI"] -->|setLocale('es')| LocaleState["locale.svelte.ts"]
    LocaleState -->|Sync| ParaglideRuntime["setLanguageTag('es')"]
    LocaleState -->|Persist| LocalStorage["localStorage ('pomody_locale')"]
    LocaleState -->|Rune update| Signal["currentTag ($state)"]
    Signal -->|Triggers| ProxyT["Proxy t.*()"]
    ProxyT -->|Fine-grained update| DOMNodes["Svelte 5 Reactive DOM"]
```

### Contrato de Implementación

```typescript
import { languageTag, setLanguageTag, type AvailableLanguageTag } from '$lib/paraglide/runtime';
import * as m from '$lib/paraglide/messages';

const STORAGE_KEY = 'pomody_locale';
export const SUPPORTED_LOCALES: readonly AvailableLanguageTag[] = ['en', 'es'] as const;

function resolveInitialLocale(): AvailableLanguageTag {
	if (typeof window === 'undefined') return 'en';
	try {
		const stored = localStorage.getItem(STORAGE_KEY);
		if (stored === 'es' || stored === 'en') {
			return stored;
		}
	} catch {
		// Ignorar restricciones en entornos sin acceso a storage
	}
	return 'en';
}

class LocaleState {
	current = $state<AvailableLanguageTag>(resolveInitialLocale());

	constructor() {
		setLanguageTag(this.current);
	}

	setLocale(tag: AvailableLanguageTag): void {
		if (tag === this.current) return;
		setLanguageTag(tag);
		this.current = tag;
		try {
			localStorage.setItem(STORAGE_KEY, tag);
		} catch {
			// Respaldo pasivo
		}
	}
}

export const localeState = new LocaleState();

/**
 * Proxy reactivo para consumo en componentes Svelte 5.
 * Intercepta las llamadas a m.*() leyendo la señal `localeState.current`
 * para registrar la dependencia reactiva a nivel de nodo.
 */
export const t = new Proxy(m, {
	get(target, prop: keyof typeof m) {
		void localeState.current;
		return target[prop];
	}
});
```

## 4. Salvaguardas de Aislamiento en Testing (Vitest Browser)

Para evitar contaminación cruzada y condiciones de carrera entre suites paralelas en Chromium:

1. **Setup Global (`afterEach`)**:
   En el arnés de test (`src/testing/` o `vitest.setup.ts`), se restablece de manera obligatoria el idioma base (`'en'`) y se limpia la clave de almacenamiento:
   ```typescript
   import { afterEach } from 'vitest';
   import { localeState } from '$lib/state/locale.svelte';

   afterEach(() => {
   	localeState.setLocale('en');
   	try {
   		localStorage.removeItem('pomody_locale');
   	} catch {
   		// No-op en entornos virtuales
   	}
   });
   ```
2. **Estrategia de Verificación por Slice**:
   - Las aserciones principales de las suites de componentes y CUJs se mantienen evaluando el idioma base en inglés (`'en'`).
   - Se incorporan pruebas atómicas dedicadas por slice que validan explícitamente la transición a `'es'` y el cambio en los copys observables.
