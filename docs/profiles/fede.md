# Perfil de Desarrollador — Fede

## Rol en Pomody
* **Rol Principal:** Vibe Coder & Lead Manual Tester / UX Feedback.
* **Área de mayor impacto:** Validación de experiencia de usuario, testing exploratorio manual e ideación/prototipado rápido asistido por IA.

## Perfil & Background
* **Perfil:** Vibe Coder (desarrollo asistido por IA) y tester humano manual, sin experiencia previa formal en desarrollo tradicional.
* **Fortalezas Principales:**
  * **Perspectiva de usuario real:** Visión no condicionada por código para detectar fricciones, inconsistencias y detalles de UX que un programador suele pasar por alto.
  * **Testing manual y exploratorio:** Capacidad de probar activamente flujos, romper casos borde y verificar la usabilidad diaria del producto.
  * **Prototipado rápido:** Uso de herramientas de IA generativa para explorar ideas visuales o funcionales preliminares.

## Objetivos de Aprendizaje en Pomody
* **Fundamentos del Desarrollo:** Adquirir nociones básicas de la estructura de una app (frontend, componentes, flujo de datos).
* **Control de Versiones y Flujo de Trabajo:** Aprender el uso cotidiano de Git y GitHub (ramas, pull requests, reporte estructurado de bugs).
* **Estructuración de Prompts:** Mejorar la precisión técnica al iterar componentes con herramientas de asistencia por IA.

## Disponibilidad & Estilo de Trabajo
* **Modalidad:** Flexible y asíncrona, enfocada en sesiones de prueba de builds y uso real ("dogfooding").
* **Comunicación:** Feedback directo en issues de GitHub con pasos para reproducir o comentarios sobre sensaciones de uso.

## Dinámica de Dupla con Vortex
* **Testing y Aprobación de UX:** Probar cada versión incremental (`v0.1`, `v0.2`, etc.) en el día a día para alimentar el modelo evolutivo con dolores reales.
* **Aportes Asistidos por IA:** Cuando proponga o genere código vía IA, hacerlo mediante ramas o PRs pequeños para que Vortex pueda revisarlo, alinearlo a la arquitectura y asegurar buenas prácticas.
