# Perfil de Desarrollador — Vortex

## Rol en Pomody
* **Rol Principal:** Full-stack Developer & Responsable Técnico / Arquitectura.
* **Área de mayor impacto:** Modelado de dominio, lógica de temporización, gestión de estado y revisión técnica.

## Perfil & Stack de Confort
* **Nivel / Título:** Full-stack TypeScript Junior Web Developer.
* **Fortalezas Principales:**
  * Backend sólido y diseño de lógica de dominio desacoplada.
  * Modelado de datos y TypeScript tipado riguroso.
  * Análisis de requerimientos y estructuración de código modular.
* **Frontend:** Nivel básico a intermedio (en desarrollo y crecimiento).

## Objetivos de Aprendizaje en Pomody
* **Fortalecer Frontend y UI/UX:** Profundizar en diseño de componentes modernos, sistemas de diseño minimalistas y pulido de interacción para equilibrar el perfil fullstack.
* **Arquitectura de Software Aplicada:** Diseñar un núcleo limpio e independiente del framework visual que facilite la evolución del producto.

## Disponibilidad & Estilo de Trabajo
* **Modalidad:** Flexible y asíncrona (ratos libres durante la semana y fines de semana).
* **Comunicación:** Issues de GitHub, seguimiento en repositorio y mensajería directa para acuerdos clave.

## Dinámica de Dupla con Fede
* **Liderazgo Técnico:** Definición de arquitectura, estructura de carpetas y estándares de código.
* **Revisión de Código (Code Review):** Supervisar y refactorizar cualquier aporte de código asistido por IA (vibe coding) para garantizar consistencia y calidad.
* **Habilitador Técnico:** Proporcionar contratos claros (APIs, tipos, interfaces) para facilitar la integración de componentes.
